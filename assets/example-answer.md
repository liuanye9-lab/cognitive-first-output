# 雅思阅读｜找到答案前，先把题干压缩成任务

定位时**只记住一个任务标签**；找到证据后，再进入**慢思考**。

你不必一边搜索原文，一边背完整题干。先决定要寻找什么，再把注意力交给原文。

## 只留下三个信息槽

| 信息槽 | 内容 |
| --- | --- |
| 对象 | **scientists**（科学家） |
| 动作 | abandon the original theory（放弃旧理论） |
| 限制与目标 | **2015 年的发现之后** → 为什么？ |

## 建议你的注意力路线

1. **读题干：理解任务** — 识别对象、动作、限制
2. **压缩题干：只保留任务标签** — 不在脑中背整句英语
3. **扫描原文：只负责定位** — 找到相关区间就停止搜索
4. **精读证据：理解原文** — 看清主干、因果与限制
5. **回看题干：逐项匹配** — 判断证据是否真的回答问题

## 关键提醒

*先定位，再理解*

> 不要一边扫原文一边在脑中完整翻译题干。**定位是找区间，精读才负责判断。**

## 先判断你卡在哪里

定位到原文后，如果立刻回头看题目，你通常是哪一种情况？

- A. 能想起要找什么，也能基本读懂原文。
- B. 记得要找什么，却读不懂关键句。
- C. 能读懂一些原文，却忘了题目问什么。

回复对应选项即可继续；文字模式没有网页提交按钮。

## 为什么这样分配注意力？

**展开第一性原理解释（可选阅读）**

工作记忆容量有限；将题干压缩成一个小的任务标签，能让你在切换到原文时少背几件事。注意：这只是训练假设，仍要靠限时做题和错因记录检验效果。
